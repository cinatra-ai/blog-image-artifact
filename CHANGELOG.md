# Changelog

All notable changes to `@cinatra-ai/blog-image-artifact`. The released artifact
is the GitHub Release tagged `v<package.json .version>` (`.github/workflows/release.yml`);
this file is the human reading of what each of those versions changed.

## 0.1.3 — 2026-09-16

- The displays read the props version the host builds a snapshot at today
  (`ARTIFACT_RENDERER_PROPS_API_VERSION` 2), and the three manifest entries
  declare it. The list row floored a live, readable artifact for its version —
  the row surface hands a display the snapshot the host built at its own
  ceiling, and never the narrowed one the artifact page passes through — so the
  same picture drew on its page and not in its row.
- The displays read the address the host names for the surface the reader is on:
  the props v2 island-scoped byte reference where the host carries one, and the
  session routes on `urls` only where it carries none. Reading `urls` on the
  island would paint a session route no subresource load can fetch there, so
  taking the version without this would have replaced a visible floor with a
  blank plate.
- A floor in the list row keeps the row's leading renderer glyph and reports the
  sanitized package, slot and reason diagnostic instead of writing a sentence
  into the row. The artifact page and the review card keep their sentence.
- The local structural copy of the renderer-props contract carries the leaf's
  edit capability and its island-scoped byte reference, so a snapshot shaped as
  the host builds one today is the shape this package is typed against.
